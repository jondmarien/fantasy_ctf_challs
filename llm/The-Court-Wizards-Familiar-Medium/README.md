# The Court Wizard's Familiar

**Category:** LLM | **Difficulty:** Medium | **Points:** 150 (dynamic)

## Lore

The Court Wizard's cat familiar knows the password to the royal vault. The Wizard enchanted it to never speak the password aloud — ancient wards burn away any utterance of the secret.

But perhaps the familiar can express it... differently.

## Your Task

Connect to the familiar's chat interface and converse with it. The familiar knows the secret, but a magical ward prevents it from speaking the password directly. Find a way around the ward.
