# The Enchanted Parrot

**Category:** LLM | **Difficulty:** Beginner | **Points:** 50 (dynamic)

## Lore

A magical parrot perches above the bar in the guild tavern. The innkeeper swears it overheard the vault combination. It loves to chat — perhaps too much.

The Quest Giver whispers: *trust no illusion.*

## Your Task

Connect to the parrot's chat interface and converse with it. The parrot knows a secret — can you get it to reveal what it heard?
